¿Qué es AstrOS?

AstrOS es un asistente inteligente desarrollado en Python con el objetivo de ayudar al usuario en diferentes tareas, proporcionando herramientas para automatización, monitoreo del sistema, reconocimiento de voz y asistencia mediante inteligencia artificial.

Características principales

🧠 Inteligencia Artificial

Responde preguntas y ayuda al usuario en diferentes tareas.

⚡ Automatización

Permite ejecutar acciones y procesos automáticamente.

💻 Monitor del sistema

Visualiza CPU, RAM, Disco, Red y temperatura.

🔒 Seguridad

Diseñado para brindar una experiencia segura y organizada.
